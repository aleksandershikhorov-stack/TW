# GENNY VIBE CHECK — dark edition

## Files
- `index.html` — the site
- `assets/` — your three supplied images

## Preview
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Free publishing (GitHub Pages)
1. Create a public repository at https://github.com/new
2. Upload `index.html` and the whole `assets` folder to the repository root.
3. Open Settings → Pages.
4. Choose “Deploy from a branch”, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the public URL.

Alternative: use https://app.netlify.com/drop and upload the project folder.

## Customize the contract address
In `index.html`, find `id="caValue"` and replace the underscores with your address text. The button copies the value once you add it.
